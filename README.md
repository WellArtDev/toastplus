# ToastPlus

Your big moments deserve a little fanfare. ToastPlus shows custom toast
notifications with sounds for the key events of every session — a warm
welcome when you log in, a dramatic alert when you die, and a fanfare
every time you level up.

## Features

- **Welcome-back toast** — "Welcome back, \<name\>!" with a chime every
  time you join a world or server
- **Death toast** — "You died!" with a low wither rumble, fired once per
  death (never spams while the death screen is up)
- **Level-up fanfare** — "Level up! Level \<n\>" with the classic
  level-up jingle every time your XP level increases
- **Custom toast style** — dark vanilla-style box with a gold accent bar
  on the left edge, title + subtitle, shown for 5 seconds
- **Zero config** — drop it in and play

## Install

1. Install [Fabric Loader](https://fabricmc.net/use/) 0.19.2+ for
   Minecraft 26.2
2. Install [Fabric API](https://modrinth.com/mod/fabric-api) for
   Minecraft 26.2
3. Drop `toastplus-1.0.0.jar` into your `mods` folder
4. Launch and play — no config needed

## Notes

- Client-side only. Works on any server (including vanilla).
- No mixins, no networking, nothing saved to disk.
